amallama

A cross-platform desktop application for managing local LLM runtimes such as llamafile. It lets the user select or download a GGUF model, switch models, and chat with the loaded model through its OpenAI-compatible endpoint.

Modules

  • amallama.core — backend services: configuration, model management, runtime control, chat client, hardware detection, and JMX monitoring. Has no JavaFX dependencies.
  • amallama.ui — JavaFX user interface: application entry point, FXML views, and controllers.

Building

Requires JDK 25. Build with mvn package; run the UI with mvn -pl ui javafx:run.
